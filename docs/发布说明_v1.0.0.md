# 微信AI助手 v1.0.0 发布说明

## 1. 版本概述

本版本聚焦“微信群聊商机智能抓取”能力，完成了从聊天消息读取、分段分析、AI识别到结果落库的完整闭环，并提供 Windows 安装包与便携版可执行文件。

适用场景：

- 从微信群聊中抓取招聘信息
- 从群消息中发现求购、采购需求
- 识别资源对接、渠道合作、服务商需求
- 识别找老师、找专家、找顾问等咨询类线索

---

## 2. 本次核心功能

### 2.1 群聊商机智能抓取

新增或完善了以下能力：

- 支持“当前群智能抓取”
- 支持“已选群批量抓取”
- 支持自动批量抓取
- 支持按最近 N 小时消息进行分析
- 支持招聘、求购、资源、专家四类重点线索抓取

### 2.2 新的识别流水线

本版本的抓取逻辑不再是简单的整段识别，而是升级为：

- 先对消息做清洗和标准化
- 按时间窗口和长度做分段
- 先分类，再做结构化提取
- 对低置信度结果进行过滤
- AI无结果时使用规则兜底
- 最终统一去重并保存

这样做的好处：

- 减少长消息导致的模型不稳定
- 降低误抓取
- 提高招聘和求购类信息的命中率
- 批量抓取时结果更稳定

### 2.3 设置页优化

设置页已重新整理，字段更少、更清楚：

- 补充“最低抓取把握度”
- 优化“抓取最近几小时消息”的说明
- 优化“Ollama 服务地址 / 优先模型 / 商机类型关键词”的说明
- 区分“显示设置”和“抓取设置”

## 4. 安装与启动建议

### 4.1 首次使用

首次打开后，建议先完成以下设置：

1. 配置微信数据目录
2. 确认本地 Ollama 已启动，或填写 OpenAI Key 作为备用
3. 设置“抓取最近几小时消息”
4. 根据需要调整“最低抓取把握度”

### 4.2 推荐默认值

建议先这样设置：

- 抓取最近几小时消息：`12` 或 `24`
- 最低抓取把握度：`0.75`
- 消息页每次加载条数：`50`
- 自动批量抓取间隔：按实际需要设置，若暂时不用可留空或关闭

## 5. 如何使用

### 5.1 智能抓取商机

适合单个群快速分析：

1. 在消息管理页打开某个群
2. 点击“智能抓取商机”
3. 系统会分析最近时间范围内的消息
4. 把识别出的商机写入待办列表

说明：

- 如果只勾选了一个群但没有打开，系统也会自动使用这个群执行单群抓取

### 5.2 批量抓取商机

适合一次巡检多个群：

1. 在左侧勾选多个群
2. 点击“批量抓取商机”
3. 系统逐群分析并汇总结果

## 6. 识别范围说明

当前版本主要抓取以下内容：

- 招聘信息
- 求购 / 采购需求
- 资源对接需求
- 找专家 / 顾问 / 咨询老师

当前默认不会重点抓取：

- 普通寒暄
- 会议通知
- 收到、谢谢、好的等简单回复
- 没有明确需求和线索的泛聊天内容

## 7. 已知说明

### 7.1 图标问题

Windows 打包所需的 `icon.ico` 已补齐，后续生成的安装包和 exe 将使用项目图标，而不是默认 Electron 图标。

### 7.2 OpenAI Key 说明

当前 OpenAI Key 主要作为备用方案使用。出于安全考虑，建议仅在需要时填写。

### 7.3 当前识别边界

当前版本仍以“文本消息抓取”为主：

- 图片内容
- 链接卡片
- 小程序卡片

暂未纳入完整商机识别流程。
